이 ZIP은 GitHub + Cloudflare Pages 루트 배포용 최종 패키지입니다.

[업로드 방법]
1. ZIP을 컴퓨터에서 압축 해제합니다.
2. 압축을 푼 폴더 안의 '내용물 전체'를 GitHub 저장소 첫 화면(루트)에 업로드합니다.
3. GitHub 첫 화면에서 아래가 바로 보여야 정상입니다.

index.html
brow-design.html
consultation-process.html
portfolio-guide.html
visit-location.html
faq-care.html
sitemap.xml
robots.txt
_headers
images/belle-myu/

중요:
- ZIP 파일 자체를 GitHub에 올리면 안 됩니다.
- BELLE_MYU_ONE_SHOT_DEPLOY 폴더 자체를 한 단계 더 안쪽에 넣으면 안 됩니다.
- images/belle-myu 폴더가 반드시 GitHub 루트 바로 아래에 있어야 합니다.
- Cloudflare 재배포가 끝난 뒤 Ctrl+F5로 강력 새로고침하세요.
